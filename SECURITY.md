# Security

## Reporting a vulnerability

Email **support@toolboxpod.com** with "Security" in the subject. Please include what you found, the steps to
reproduce it, and how to reach you. Do not open a public issue or post details before we have replied.

This covers the hosted MCP server at `https://mcp.toolboxpod.com/mcp` (OAuth 2.1 sign-in and its tools), the
toolboxpod.com website and API, and the connection files and plugin manifests in this repository.

## What this repository holds

Connection details, listing files and plugin manifests only. The server runs as a hosted service by Toolbox Brands
LLC; its source is not in this repository, and there is nothing here to install or run besides the files an AI app
reads to connect.

## Supported versions

Only the current hosted server and the current files on `main` are supported.
